# 产品范围 · 0.2.0

目标使用者为需要整理邮件、公告和研报的研究人员。待验证假设是：去重、事实整理与证据回查值得自动化。目前没有研究员访谈或工时改善数据。

本期交付为纯 Python 包与 CLI，输入本地材料，输出事实、出处、疑似冲突、失败清单、执行指标和简报。

| 能力 | 验收标准 |
|---|---|
| 增量导入 | 跳过未变化文件；相同正文保留多个来源 |
| 长文处理 | 遍历全部有效分块；失败块可见 |
| 证据校验 | 指定段落逐字引文，带正文偏移和 PDF 页码 |
| 推理接口 | 规则/LLM 共用领域模型和校验器 |
| 有界修复 | 格式/引用错误最多修复配置次数 |
| 可恢复 | 中断恢复，失败可重试，成功块复用 |
| 可观察 | 配置、提示词哈希、tokens、逐块事件 |
| 人工复核 | 追加署名记录，导出保留历史 |

不包含：自动邮箱同步、付费数据源、OCR、财务模型修改、交易建议、团队权限和公开服务部署。

先用 SQLite 和 Provider Protocol 建立可测试的本地处理流程，再根据真实使用反馈决定连接器、权限及存储扩展。下一阶段使用 20–30 份获准材料比较人工、规则、模型流程，记录遗漏、修改量和总耗时。
